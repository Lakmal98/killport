# killport docs

`killport` is a production-ready Bash CLI for terminating processes bound to one or more ports.

## Quick start

```bash
npm install
npm run docs:dev
```

For deployment, Vercel uses:

- `buildCommand`: `npm run docs:build`
- `outputDirectory`: `docs/.vitepress/dist`

See [Usage](./usage.md), [Downloads](./downloads.md), and [Troubleshooting](./troubleshooting.md).
